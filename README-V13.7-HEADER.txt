EL Hedaya V13.7 — Luxury Islamic Header

This patch replaces the plain public header with the new premium design:
- ivory/frosted center
- deep emerald Islamic side panels
- subtle geometric texture
- gold trim and divider
- crescent and lantern ornaments
- larger official EL Hedaya logo
- animated navigation underline
- premium Register CTA
- fully redesigned mobile navigation

INSTALL
1. Extract this ZIP.
2. Copy the src folder DIRECTLY over your Git-connected project root src folder.
3. Replace matching files.
4. Run:
   npm run build
   git add -A
   git commit -m "Add luxury EL Hedaya header"
   git push origin main
5. Wait for Vercel and hard-refresh the website.

No environment-variable or database changes are required.
